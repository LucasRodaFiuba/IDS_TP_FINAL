# IDS_TP_FINAL
Proyecto final IDS 2026 – sitio gastronómico con reservas

​Sitio web gastronómico con reserva.​
​reación de un sitio web que ofrezca para el rubro gastronómico, (restaurante, cafetería-bar,
​comida rápida, etc).​
​El alcance mínimo del sitio web es el siguiente:​
​●​ F
​ rontend con información del lugar, fotos, reseñas, menú con precios, opción de realizar​
​una reserva.​
​●​ ​Se deberá tener un acceso de administrador para realizar los ABM, ver estadísticas y​
​cualquier otra modificación sobre el Front.​
​●​ ​ABM del menú, con imágenes de los platos y restricciones alimenticias​
​●​ ​ABM reseñas. Las mismas son publicadas por los usuarios una vez que acuden al lugar​
​luego de una reserva​
​●​ ​ABM de servicios extras (acceso discapacitados, playa de estacionamiento,​
​●​ ​Reservas. Las mismas se deben hacer en forma ágil, días disponibles -> horario ->​
​cantidad de personas -> confirmación al email. Cuando se hace una reserva se crea un​
​QR con los datos de la misma. Este QR es escaneado en el local cuando se anuncie el​
​comensal.​
​●​ ​El QR de la reserva debe ser enviado por mail y debe tener un botón cancelar, para el​
​caso de que el comensal anule la reserva.​
​●​ ​Se requieren dashboard informativos dentro del rol administrador, donde haya​
​información sobre cantidad de reservas, historial de reservas, usuarios que hayan​
​cancelado la reserva, etc.​
​●​ ​Es deseable, pero no obligatorio​
​○​ ​Dockerizar el proyecto​
​○​ ​Hostear el proyecto en pythonanywhere o similar​
